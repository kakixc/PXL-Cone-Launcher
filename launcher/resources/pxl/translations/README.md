# Bundled translations

upstream-ru.qm is the Russian Prism Launcher translation distributed by the official https://i18n.prismlauncher.org/ index, retrieved 2026-10-26. Source file 4c60bfe767e3d0f8275e29dd470421516afcce30.class; SHA-1 4c60bfe767e3d0f8275e29dd470421516afcce30 verified at download. The compiled Qt catalog is bundled as an offline fallback; local upstream translations still take priority. Upstream translation sources and contributors: https://hosted.weblate.org/projects/prismlauncher/launcher/ . Distributed under the repository GPL-3.0 license.

pxl-ru.po contains PXL-specific UI phrases and uses the existing POTranslator. It is installed after the upstream catalog so new PXL strings are translated without modifying downloaded files. English uses the source strings. Other upstream languages remain available.
