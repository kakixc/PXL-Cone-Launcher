# PXL Cone 0.1.0-alpha.1

Release notes prepared for the first public alpha. This document does not announce that downloads are available.

## Your Minecraft. Your space.

PXL Cone brings its own interface to the PineconeMC / Prism foundation. Keep your instances together, find additions for your game and share a setup with a friend.

### In this alpha

- Home with quick launch, playtime and a library with three saved views: cover tiles, PXL hybrid cards and a detailed list.
- Instance creation with Minecraft and loader selection. A downloading instance appears in the library with progress before it is ready to play.
- Modrinth and CurseForge content browsing, installed-content management, dependency review, updates and version selection using the existing provider infrastructure.
- A compact downloads panel and the ability to hide progress while supported tasks continue in the background.
- English and Russian, a skippable first-run guide, basic and advanced settings, wallpaper and instance covers.
- Microsoft, Ely.by and offline profiles with a quick account picker.
- Per-instance descriptions and a screenshot gallery with clipboard copy, folder export and use as an instance cover.
- PXL archive sharing and transfer, plus supported upstream pack import/export routes.
- Automatic Java selection and download, with a PXL interface for manual runtime selection.
- Update notifications and Markdown release notes. Application updates are installed manually.

### Known limitations

- Linux AppImage is experimental and has not been manually tested on a desktop Linux system. Application startup, Minecraft launch and desktop integration are not confirmed.
- This is an alpha: not every game version, loader, provider and account combination has been tested.
- Actual download pause/resume is not implemented. Hiding progress does not cancel the task.
- OptiFine installation remains a manual workflow.
- Some advanced tools still use upstream dialogs. English and Russian coverage is still being refined.
- The Inno Setup alpha installer does not register archive or browser-link associations. Use Import inside the launcher to open packs.
- Task history lasts for the current launcher session.
- Automatic executable replacement, animated banners, AI pack creation and community themes are not features of this alpha.

Keep a backup of important worlds before updating Minecraft, loaders or mods. Include your operating system, launcher version and reproduction steps when reporting a problem through the repository's Issues page. Remove account tokens and other private information from any logs you share.

## Русский

### Ваш Minecraft. Ваше пространство.

Первая альфа PXL Cone объединяет собственный интерфейс с основой PineconeMC / Prism: библиотека с тремя режимами, создание сборок, поиск и установка дополнений, управление контентом, аккаунты, автоматическая Java, скриншоты и перенос сборок.

Есть русский и английский интерфейс, пропускаемый мастер знакомства, обычный и продвинутый режимы настроек, свои фоны, обложки и описания сборок. Создаваемые сборки показываются в библиотеке с прогрессом; поддерживаемую фоновую загрузку можно скрыть. Обновления лаунчера устанавливаются вручную.

### Известные ограничения

- Linux AppImage экспериментальный и пока не проверен вручную на настольной Linux-системе. Запуск приложения, Minecraft и интеграция с рабочим столом не подтверждены.
- Проверены не все сочетания версий игры, загрузчиков, источников контента и аккаунтов.
- Настоящей паузы/продолжения загрузок пока нет. Скрытие прогресса не отменяет задачу.
- OptiFine устанавливается вручную; некоторые продвинутые инструменты пока используют прежние диалоги. Перевод ещё дорабатывается.
- Установщик альфы Inno Setup пока не регистрирует ассоциации архивов и браузерных ссылок. Для открытия сборок используйте «Импорт» в лаунчере.
- История задач хранится в пределах сеанса. Автоматическая замена EXE, анимированные баннеры, AI-сборки и темы сообщества в эту альфу не входят.

Сохраняйте резервные копии важных миров перед обновлением игры, загрузчика или модов. В сообщении об ошибке через Issues репозитория укажите ОС, версию лаунчера и шаги воспроизведения. Перед отправкой логов удалите токены и другие личные данные.
